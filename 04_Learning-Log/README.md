# 04 Learning Log

## Scope
记录周学习日志、会议纪要、读书心得与技术调研。

## Suggested Rhythm
- Weekly：总结进展、阻塞点与下周重点。
- Monthly：回顾积累质量并调整学习策略。

## Suggested Files
- `weekly-log-template.md`
- `meeting-notes-template.md`
- `monthly-retrospective-template.md`

## Logging Rule
- 周记记录事实、判断和下周行动，不写成单纯流水账。
- 会议纪要优先记录决策、分歧、责任人与截止时间。
- 月度复盘关注方向是否需要调整，而不是只统计完成事项。

## Review Questions
- 这个月最值得复用的技术结论是什么？
- 哪个方向投入产出比最低，需要停止或降级？
- 下个月最小可交付成果是什么？

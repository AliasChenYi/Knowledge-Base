# Experiment Log Index

## Purpose
集中记录实验状态，避免 idea、实验脚本、结果截图和最终判断分散在不同位置。

## Status Legend
- `Backlog`：已记录但未开始。
- `Running`：正在跑或正在分析。
- `Blocked`：缺数据、算力、代码或决策。
- `Done`：完成并产生结论。
- `Stopped`：主动停止，不再投入。

## Weekly Review
- 更新 Running / Blocked 实验状态。
- 把 Done 实验的结论迁移到工程笔记。
- 对超过两周没有推进的 Backlog 做 stop / keep 判断。
- 对 Stopped 实验记录停止原因，避免重复投入。

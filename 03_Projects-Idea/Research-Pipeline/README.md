# Research Pipeline

## Scope
用统一流程管理 idea 验证，避免实验记录碎片化。

## Flow
1. 定义 hypothesis 与预期收益。
2. 设计最小实验（minimal experiment）与指标。
3. 执行并分析，做出 continue / pivot / stop 决策。

## Core Files
- `idea-template.md`
- `experiment-template.md`
- `experiment-log-index.md`

## Decision Rule
- `Continue`：指标达到预期，且风险可控。
- `Pivot`：方向有价值，但当前方法或假设需要调整。
- `Stop`：结果不支持投入，或成本明显高于收益。

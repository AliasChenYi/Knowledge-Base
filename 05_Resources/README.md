# 05 Resources

## Scope
沉淀值得反复回看的外部高质量资源。

## Categories
- `blogs.md`：高质量技术博客。
- `github-repos.md`：实用开源仓库与实现。
- `courses.md`：课程与讲义资源。
- `tools.md`：效率工具与工程平台。

## Curation Rules
- 每条链接都写一行“为什么值得看”。
- 建议补充标签（topic、difficulty、use-case）。
- 定期清理过时或低价值资源。

## Entry Format
```md
- [Name](URL) - `topic` / `difficulty` / `use-case`：为什么值得反复看。
```

## Review Policy
- 新增资源前先判断是否能支持当前论文阅读、工程优化或项目验证。
- 如果一个资源 3 个月内没有被再次引用，补充保留原因或移出推荐区。
- 对工具类资源，优先记录实际工作流，而不是只保存官网链接。

# 脚本模板

这个目录放一些入职后会反复用的小脚本模板。它们默认不依赖项目内部环境，主要用于学习和改造。

脚本：

1. [env_report.py](env_report.py)：收集 Python/PyTorch/Triton/CUDA 环境信息。
2. [benchmark_utils.py](benchmark_utils.py)：简单 benchmark 统计工具。
3. [correctness_utils.py](correctness_utils.py)：误差统计和 allclose 辅助。
4. [shape_sweep_template.py](shape_sweep_template.py)：shape sweep 实验模板。
5. [support_matrix_template.md](support_matrix_template.md)：算子支持矩阵模板。

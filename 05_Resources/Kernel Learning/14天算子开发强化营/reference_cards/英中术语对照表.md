| tensor | 张量 | 多维数组 |
| operator / op | 算子 | 张量操作 |
| kernel | 内核/设备函数 | 设备上执行的程序 |
| shape | 形状 | 每个维度大小 |
| stride | 步长 | 逻辑维度到内存偏移 |

| broadcast | 广播 | 小张量扩展参与计算 |

# 算子开发术语速查卡：扩展版

## 1. 张量与算子

| 术语 | 解释 |
|---|---|
| Tensor | 多维数组，包含 data、shape、stride、dtype、device |
| Operator / Op | 张量操作，如 matmul、softmax |
| Kernel | 设备上实际执行的并行程序 |
| Shape | 张量每个维度的大小 |
| Stride | 每个维度移动一步对应的内存偏移 |
| Layout | 数据排列方式，如 NCHW、NHWC、row-major |
| Contiguous | 数据按默认顺序连续排列 |
| Broadcast | 小 shape 按规则扩展参与计算 |
| Dtype | 数据类型，如 FP32、FP16、BF16、INT8 |

## 2. 硬件

| 术语 | 解释 |
|---|---|
| SM | NVIDIA GPU 的 Streaming Multiprocessor |
| CU | AMD GPU 的 Compute Unit |
| Warp | NVIDIA 中一组一起调度的线程，常见 32 线程 |
| Wavefront | AMD 类似概念，具体大小看架构 |
| Register | 线程私有最快存储 |
| Shared memory | block 内共享的片上 SRAM |
| Global memory | 设备显存/HBM |
| L2 cache | 设备级缓存 |
| Tensor Core | NVIDIA 矩阵乘专用硬件单元 |
| MMA | Matrix Multiply-Accumulate |

## 3. 性能

| 术语 | 解释 |
|---|---|
| FLOPs | 浮点运算次数 |
| FLOP/s | 每秒浮点运算能力 |
| TFLOPS | 每秒万亿次浮点运算 |
| Bandwidth | 带宽，每秒可搬运数据量 |
| Arithmetic Intensity | FLOPs / Bytes |
| Memory-bound | 瓶颈在数据搬运 |
| Compute-bound | 瓶颈在计算吞吐 |
| Launch overhead | kernel 启动开销 |
| Occupancy | 活跃 warp/block 占硬件资源比例 |
| Coalescing | 相邻线程访问连续地址 |
| Bank conflict | shared memory bank 冲突 |
| Spill | 寄存器不够，变量溢出到更慢存储 |

## 4. 优化动作

| 术语 | 解释 |
|---|---|
| Tiling | 分块，提高数据复用 |
| Fusion | 合并多个 op，减少中间 tensor 和 launch |
| Vectorized load/store | 一次加载/写入多个连续元素 |
| Unroll | 循环展开，减少循环控制开销 |
| Prefetch | 提前搬数据 |
| Pipeline | 搬运和计算重叠 |
| Epilogue | GEMM 主计算后的输出处理 |
| Autotuning | 自动搜索 tile/block 参数 |

## 5. 框架与编译器

| 术语 | 解释 |
|---|---|
| PyTorch Dispatcher | PyTorch 根据 backend/dtype/device 选择实现 |
| Custom Op | 用户自定义算子 |
| Meta kernel | 只推导 shape/dtype，不做真实计算 |
| HLO / StableHLO | 高层张量 IR |
| MLIR Dialect | MLIR 中某一层抽象的 IR 方言 |
| TVM TensorIR | TVM 的张量程序 IR |
| Schedule | 对 loop/tile/vectorize 等优化的描述 |

## 6. LLM 相关

| 术语 | 解释 |
|---|---|
| Attention | `softmax(QK^T)V` |
| MHA | Multi-Head Attention |
| MQA | Multi-Query Attention |
| GQA | Grouped-Query Attention |
| KV Cache | 推理时缓存历史 K/V |
| PagedAttention | 用分页方式管理 KV cache |
| FlashAttention | IO-aware exact attention |
| Quantization | 量化，如 INT8/INT4/FP8 |
| Weight-only | 只量化权重，激活保持较高精度 |

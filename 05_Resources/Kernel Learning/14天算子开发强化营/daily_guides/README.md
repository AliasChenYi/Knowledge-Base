# 逐日超详细讲义

这个目录是对主计划 [14天详细学习计划.md](../14天详细学习计划.md) 的加厚版。主计划告诉你“14 天学什么”，这里告诉你“每天具体怎么学、看哪里、写什么、怎么验证”。

建议用法：

1. 每天先打开对应 `dayXX_*.md`。
2. 先看当天图片，建立直觉。
3. 按“2 小时最低版”完成基本闭环。
4. 时间够再做“4-6 小时完整版”。
5. 每天都留下一个文件：笔记、代码、benchmark 表或论文总结。

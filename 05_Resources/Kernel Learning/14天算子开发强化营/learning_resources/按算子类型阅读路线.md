# 按算子类型阅读路线

## 1. Elementwise / Broadcast / Fusion

代表算子：

- add
- mul
- relu
- gelu
- bias add
- residual add

先读：

1. CUDA Programming Guide：thread hierarchy。
2. Triton vector add tutorial。
3. PyTorch Performance Tuning Guide：fusion。

动手：

- `y = relu(x * scale + bias)`
- 支持 contiguous。
- 对比 PyTorch eager。

关键问题：

- 是否 memory-bound？
- 是否 launch-bound？
- fusion 后寄存器压力是否增加？

## 2. Transpose / Layout Conversion

代表算子：

- transpose
- permute
- NCHW <-> NHWC
- pack/unpack

先读：

1. NVIDIA Efficient Matrix Transpose。
2. CUDA Best Practices：coalescing/shared memory。

动手：

- naive transpose。
- tiled transpose。
- 加 padding 减少 bank conflict。

关键问题：

- 读写哪一边不连续？
- shared memory 是为了缓存，还是为了改变访问模式？
- layout conversion 是否吃掉端到端收益？

## 3. Reduction

代表算子：

- sum
- max
- mean
- variance
- argmax

先读：

1. NVIDIA Optimizing Parallel Reduction。
2. CUDA Best Practices：shared memory。
3. Triton reduction 相关教程。

动手：

- row-wise sum。
- row-wise max。
- 支持非 2 的幂长度。

关键问题：

- identity value 是什么？
- FP16 是否 FP32 accumulate？
- 一个 block 是否能处理整行？
- 是否需要跨 block reduction？

## 4. Softmax / LogSoftmax

先读：

1. Triton Fused Softmax。
2. FlashAttention 里 online softmax 部分。

动手：

- stable softmax。
- fused softmax。
- causal masked softmax。

关键问题：

- 是否减 max？
- mask 填 `-inf` 是否正确？
- 行太长怎么办？
- 是否拆成多个 kernel 导致 HBM 中间写回？

## 5. LayerNorm / RMSNorm

先读：

1. PyTorch LayerNorm docs。
2. Triton LayerNorm tutorial。
3. LLM RMSNorm 实现。

动手：

- LayerNorm forward。
- RMSNorm forward。
- FP16 input + FP32 accumulate。

关键问题：

- eps 加在哪里？
- variance 定义是否和 reference 一致？
- weight/bias shape 是否正确？
- hidden size 对 block size 有什么影响？

## 6. GEMM / Matmul / Batched GEMM

先读：

1. NVIDIA Matrix Multiplication Background。
2. CUTLASS Efficient GEMM。
3. Triton Matmul tutorial。

动手：

- naive GEMM。
- shared-memory tiled GEMM。
- Triton matmul。
- CUTLASS example。

关键问题：

- M/N/K 是什么？
- 算术强度如何？
- 是否使用 Tensor Core/MMA？
- epilogue 能否融合 bias/activation？
- 小 batch/GEMV 是否和大 GEMM 不同？

## 7. Convolution

先读：

1. NVIDIA Convolutional Layers Performance Guide。
2. cuDNN Developer Guide。
3. CUTLASS implicit GEMM convolution。

动手：

- naive 2D convolution。
- im2col + GEMM。
- 理解 implicit GEMM。

关键问题：

- NCHW/NHWC 哪个更适合目标硬件？
- filter/layout 如何影响连续访问？
- convolution 是否最终走 GEMM-like path？

## 8. Attention

先读：

1. 普通 attention 公式。
2. FlashAttention 2022。
3. FlashAttention-2。
4. PagedAttention。

动手：

- ordinary attention。
- mini FlashAttention forward。
- KV cache memory estimate。

关键问题：

- `N x N` 中间矩阵有多大？
- online softmax 怎么合并 block？
- causal mask 怎么处理？
- decode 阶段和 prefill 阶段有什么不同？

## 9. Quantized GEMM/GEMV

先读：

1. SmoothQuant。
2. AWQ。
3. LLM.int8。
4. TensorRT-LLM Quantization。

动手：

- INT8 weight-only GEMV。
- per-channel scale。
- dequant fusion。

关键问题：

- scale 粒度是什么？
- 权重 pack 格式是什么？
- accumulation dtype 是什么？
- 硬件是否支持对应低精度指令？

## 10. Communication-related Operators

代表：

- allreduce
- reduce-scatter
- allgather
- all-to-all

先读：

1. PyTorch Distributed docs。
2. NCCL docs。
3. vLLM / TensorRT-LLM serving 相关资料。

关键问题：

- 通信量是多少？
- 是否能和计算 overlap？
- 是 tensor parallel、pipeline parallel，还是 expert parallel？

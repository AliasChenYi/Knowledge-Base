# 论文阅读路线：从入门到资深

这个路线不是按发表时间，而是按“读懂难度”和“对算子开发的启发”排序。

## 第一阶段：性能模型和基础模式

### 1. Roofline

本地 PDF：[Roofline](../papers/01_Roofline_EECS-2008-134.pdf)

你要读懂：

- 算术强度。
- memory-bound。
- compute-bound。
- 为什么优化前要先判断瓶颈。

读后输出：

```text
用 Roofline 分析 vector add、softmax、GEMM。
```

### 2. NVIDIA Reduction

本地 PDF：[NVIDIA Reduction](../papers/02_NVIDIA_Optimizing_Parallel_Reduction.pdf)

你要读懂：

- 树形归约。
- 分支发散。
- shared memory。
- bank conflict。

读后输出：

```text
实现 row-wise sum/max。
```

## 第二阶段：DSL 和手写 kernel 的桥梁

### 3. Triton

本地 PDF：[Triton](../papers/03_Triton_MAPL2019.pdf)

你要读懂：

- tile-level programming。
- 为什么比 CUDA 更容易写某些 ML kernel。
- block tensor 的思想。

读后输出：

```text
Triton fused softmax。
```

### 4. Halide

本地 PDF：[Halide](../papers/10_Halide_PLDI2013.pdf)

你要读懂：

- algorithm 和 schedule 分离。
- 为什么“算什么”和“怎么调度”要分开。
- 这对 TVM/TensorIR 的思想有帮助。

读后输出：

```text
写一页 algorithm/schedule 分离笔记。
```

## 第三阶段：深度学习编译器

### 5. TVM

本地 PDF：[TVM](../papers/07_TVM_OSDI2018.pdf)

你要读懂：

- graph-level optimization。
- operator-level optimization。
- schedule search。
- 跨硬件 codegen。

读后输出：

```text
画 TVM 编译流程图。
```

### 6. Ansor

本地 PDF：[Ansor](../papers/08_Ansor_OSDI2020.pdf)

你要读懂：

- 自动生成 tensor program。
- 搜索空间。
- cost model。
- auto-tuning 为什么重要。

读后输出：

```text
解释手写 schedule 和自动调优的区别。
```

### 7. MLIR

本地 PDF：[MLIR](../papers/09_MLIR_2020.pdf)

你要读懂：

- 多层 IR。
- dialect。
- lowering。
- pattern rewrite。

读后输出：

```text
看完 MLIR Toy Tutorial 前 2-3 章。
```

## 第四阶段：Attention 与 LLM serving

### 8. FlashAttention

本地 PDF：[FlashAttention](../papers/04_FlashAttention_NeurIPS2022.pdf)

你要读懂：

- IO-aware。
- online softmax。
- 为什么避免 `N x N` 中间矩阵写回。

读后输出：

```text
mini FlashAttention forward 伪代码。
```

### 9. FlashAttention-2

本地 PDF：[FlashAttention-2](../papers/05_FlashAttention2.pdf)

你要读懂：

- work partitioning。
- 为什么 FA1 仍有非 matmul 开销。
- 如何提高并行度。

### 10. FlashAttention-3

本地 PDF：[FlashAttention-3](../papers/06_FlashAttention3.pdf)

你要读懂：

- Hopper 特性。
- 异步流水。
- FP8。

第一遍只读摘要和 introduction 就够。

### 11. PagedAttention

本地 PDF：[PagedAttention/vLLM](../papers/11_PagedAttention_vLLM.pdf)

你要读懂：

- LLM serving 的 KV cache 内存问题。
- 分页管理思想。
- 为什么 serving 优化不只是单 kernel 优化。

读后输出：

```text
画 prefill/decode 阶段 KV cache 数据流。
```

## 第五阶段：量化

### 12. LLM.int8

本地 PDF：[LLM.int8](../papers/14_LLM_int8_NeurIPS2022.pdf)

你要读懂：

- outlier activation。
- 为什么 LLM INT8 不只是普通量化。

### 13. SmoothQuant

本地 PDF：[SmoothQuant](../papers/12_SmoothQuant.pdf)

你要读懂：

- W8A8。
- 平滑 activation outlier。
- 把难量化的部分迁移到 weight。

### 14. AWQ

本地 PDF：[AWQ](../papers/13_AWQ_MLSys2024.pdf)

你要读懂：

- activation-aware。
- INT4 weight-only。
- group-wise quantization。

读后输出：

```text
对比 LLM.int8 / SmoothQuant / AWQ 的目标、粒度和适用场景。
```

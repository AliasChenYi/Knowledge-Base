# 中文资料使用建议

中文资料很有帮助，但要会用。

## 1. 中文资料适合做什么

适合：

- 快速建立直觉。
- 了解术语翻译。
- 看别人踩坑。
- 找入门代码。
- 辅助理解论文。

不适合：

- 当作最终事实来源。
- 直接复制性能结论。
- 不看版本和硬件条件就套用参数。

## 2. 推荐使用方式

看中文博客时，固定问：

1. 作者用的硬件是什么？
2. CUDA/框架版本是什么？
3. shape 是什么？
4. baseline 是谁？
5. 有没有 correctness？
6. 有没有 profiler 证据？
7. 结论是否能回到官方文档或论文验证？

## 3. 遇到冲突怎么办

如果中文博客和官方文档冲突：

```text
以官方文档/论文为准。
```

如果两个博客结论不同：

```text
看硬件、版本、shape、dtype、baseline 是否一致。
```

如果仍然不确定：

```text
自己写最小实验验证。
```

```text
中文资料帮你入门，官方文档和论文帮你站稳，自己的实验帮你真正掌握。
```

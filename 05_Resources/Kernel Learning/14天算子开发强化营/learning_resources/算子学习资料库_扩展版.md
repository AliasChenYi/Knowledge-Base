# 算子学习资料库：扩展版

这份资料库只收“值得反复读”的资料。优先级如下：

- A：官方文档、官方教程、顶会/期刊论文、官方规范。
- B：官方技术博客、作者团队博客、官方 GitHub。
- C：个人博客、二次整理、论坛经验帖。只作为辅助理解，不作为最终依据。

## 1. 总体学习顺序

如果你完全从零开始，建议按这个顺序：

```text
硬件与 CUDA 基础
-> 内存访问与 reduction
-> softmax / norm
-> PyTorch custom op / Triton
-> GEMM / CUTLASS
-> attention / FlashAttention
-> 量化与 LLM serving
-> TVM / MLIR / 编译器
-> 多后端迁移
```

不要一上来读 FlashAttention-3 或 CUTLASS 源码。先把 vector add、transpose、reduction、softmax、RMSNorm 跑通。

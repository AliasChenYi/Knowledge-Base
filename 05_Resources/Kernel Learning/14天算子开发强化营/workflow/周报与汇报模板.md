## 2. 性能任务汇报模板

```text
任务：优化 X 算子

背景：
该算子用于 Y 模型/链路，目标 shape 为 Z。

Baseline：
baseline 是 A，性能为 B。

正确性：
reference 是 C，误差标准为 D，已覆盖 shape E。

Profiling：
观察到 F，判断瓶颈为 G。

优化：
做了 H 改动。

结果：
在 shape 1 上从 a ms 到 b ms；
在 shape 2 上从 c ms 到 d ms；
在 shape 3 上无收益。

风险：
当前不支持 I。

下一步：
计划 J。
```

## 3. 向 mentor 求助模板

不要只说：

```text
我跑不通。
```

建议说：

```text
我在跑 X 算子的 benchmark，命令是 A，环境是 B。
当前错误是 C。
我已经检查了 D/E/F，怀疑是 G。
相关日志在 H。
想请你帮我确认一下是不是 I 的问题。
```

## 4. 会议前准备清单

- [ ] 我要汇报的目标是什么？
- [ ] 有没有数据表？
- [ ] 有没有 correctness 结果？
- [ ] baseline 是否清楚？
- [ ] 风险是否清楚？
- [ ] 我需要别人决策什么？

## 5. 让人放心的表达方式

少说：

```text
应该快了。
```

多说：

```text
在这 5 个 benchmark shape 中，有 3 个 shape 有 1.2x-1.5x 收益，2 个 shape 无收益。无收益 shape 的共同点是 N 较小，launch overhead 占比较高。
```

少说：

```text
我觉得是访存问题。
```

多说：

```text
profiling 显示 compute utilization 较低，而 memory throughput 较高，加上该算子 FLOPs/Byte 较低，所以我判断更偏 memory-bound。
```

# 入职前知识地图

这份地图帮你把 14 天内容放到一张“能力树”里。你不需要一次性全会，但要知道每个知识点在哪一层。

## 第一层：基础工程

你要能做：

- 写 C++/Python。
- 编译运行小程序。
- 用 Git 管理代码。
- 用 pytest 或简单脚本做测试。
- 记录环境和实验结果。

对应材料：

- [环境准备与工具链](环境准备与工具链.md)
- [实验记录模板](templates/实验记录模板.md)

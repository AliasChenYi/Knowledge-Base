# 四个进阶小项目任务书

完成 14 天主线后，可以从下面四个项目里选一个做深。不要贪多，每个项目都要做成完整闭环。

## 项目 1：RMSNorm 全流程优化

### 目标

实现并优化 RMSNorm forward。

### 支持范围

```text
input: [M, N], contiguous
weight: [N]
dtype: FP16/FP32
output: same shape as input
```

### 必做

- PyTorch reference。
- Triton 实现。
- correctness tests。
- shape sweep。
- benchmark。
- 性能报告。

### 进阶

- 支持 BF16。
- 支持 non-contiguous fallback。
- PyTorch custom op 接入。
- backward。

## 项目 2：Fused Bias + GELU

### 目标

把：

```text
y = gelu(x + bias)
```

融合成一个 kernel。

### 必做

- PyTorch reference。
- Triton/CUDA 实现。
- 对比 PyTorch eager。
- 测小 shape 和大 shape。

### 重点

- elementwise fusion。
- launch overhead。
- vectorized load/store。
- approximate GELU 与 exact GELU 语义差异。

## 项目 3：INT8 Weight-only GEMV 玩具版

### 目标

实现：

```text
y[n] = sum_k x[k] * (w_int8[n,k] * scale[n])
```

### 必做

- Python quantize/dequant reference。
- Triton 或 CUDA GEMV。
- correctness。
- 不同 N/K benchmark。

### 重点

- scale 粒度。
- dequant fusion。
- INT8 权重读取。
- accumulation dtype。

## 项目 4：Mini FlashAttention Forward

### 目标

实现 forward-only single-head FlashAttention 玩具版。

### 支持范围

```text
Q/K/V: [N, D]
causal: optional
dtype: FP32 first
```

### 必做

- 普通 attention reference。
- 分块 attention 伪代码。
- online softmax。
- correctness。
- 显存读写分析。

### 进阶

- FP16 输入、FP32 accumulation。
- causal mask。
- 多 head。
- benchmark。

# 01 Papers

## Scope
本目录用于存放结构化论文笔记，按主题方向归档。

## Subdirectories
- `AI-Infra/`：Kernel、memory、distributed runtime 等系统论文。
- `Architecture/`：Transformer、Mamba 等模型架构论文。

## Intake Rule
- 先判断论文是否服务于当前研究问题，再决定是否精读。
- 精读论文使用 `paper-template.md`，略读论文也至少记录一句结论与一条可复用点。
- 文件名使用 `year-venue-short-title.md`，标题过长时保留最能检索的关键词。

## Review Workflow
1. `First pass`：问题、贡献、关键图表和结论。
2. `Second pass`：方法细节、实验设置、限制和复现成本。
3. `Transfer`：提炼能迁移到 `02_AI-Infra/` 或 `03_Projects-Idea/` 的方法。
4. `Follow-up`：记录下一篇要读的论文、源码或实验。

## Writing Standard
- 记录问题定义、方法核心、贡献点、局限性。
- 对重点论文补充可复现实验想法（reproducible ideas）。
- 每篇论文一篇笔记，便于后续检索与回看。

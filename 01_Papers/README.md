# 01 Papers

## Scope
本目录用于存放结构化论文笔记，按主题方向归档。

## Subdirectories
- `3D-Vision/`：3D pose estimation、reconstruction、neural rendering 方向。
- `AI-Infra/`：Kernel、memory、distributed runtime 等系统论文。
- `Architecture/`：Transformer、Mamba 等模型架构论文。

## Writing Standard
- 记录问题定义、方法核心、贡献点、局限性。
- 对重点论文补充可复现实验想法（reproducible ideas）。
- 每篇论文一篇笔记，便于后续检索与回看。
